## 1. Project Description

ResearchFinder is a computerized web-based student research project
search engine system developed to help students search, discover,
and explore academic research project topics.

The application provides a centralized interface where users can
search for research projects using keywords, project titles,
authors, and abstracts.

Users can also filter projects by academic department and
research category.

The system includes project management features that allow users
to add, edit, and delete research project records.

ResearchFinder was developed using HTML, CSS, and JavaScript.

Browser Local Storage is used to save research project records,
favorite projects, and theme preferences.


## 2. Problem Statement

Students often experience difficulties when searching for
research project topics and related academic materials.

Research project information may be scattered across different
sources, making it difficult to locate relevant topics.

Manual searching can also be time-consuming, especially when
students need to find projects from a particular department
or research category.

ResearchFinder addresses this problem by providing a simple
computerized platform where academic project records can
be organized, searched, filtered, and viewed.



## 3. Aim of the Project

The aim of this project is to design and implement a
computerized student research project search engine system
that enables students to search, retrieve, and explore
academic research project information conveniently.

## 10. How to Use ResearchFinder

### Searching for Projects

1. Open ResearchFinder.
2. Click Browse Projects.
3. Enter a keyword in the search field.
4. View matching research projects.

### Filtering Projects

1. Open Browse Projects.
2. Select a department.
3. Select a research category.
4. View the filtered results.

### Viewing Project Details

1. Browse the available projects.
2. Click View Details.
3. Read the project title, author, abstract, and keywords.

### Adding a Research Project

1. Click Add Project.
2. Enter the project title.
3. Enter the author's name.
4. Select the department.
5. Select the research category.
6. Enter the project year.
7. Enter relevant keywords.
8. Enter the project abstract.
9. Click Save Project.

### Editing a Research Project

1. Click Manage Projects.
2. Find the project.
3. Click Edit.
4. Update the required information.
5. Click Save Project.

### Deleting a Research Project

1. Click Manage Projects.
2. Find the project.
3. Click Delete.
4. Confirm the deletion.

### Saving Favorite Projects

1. Open Browse Projects.
2. Find a project.
3. Click the star icon.
4. Open My Favorites to view saved projects.

### Switching Themes

1. Click Dark Mode to enable the dark theme.
2. Click Light Mode to return to the original theme.

## 11. Search Engine Functionality

ResearchFinder uses JavaScript to search through
research project records.

The search function checks:

- Project titles
- Author names
- Abstracts
- Keywords
- Departments
- Categories

The application compares the entered search term
with the available project information and displays
matching results.

Users can also apply department and category filters
to narrow the results.

The system searches its own stored project records.
It does not search the internet.

---

## 12. Data Storage

ResearchFinder uses browser Local Storage.

The following storage keys are used:

- researchfinder_projects
- researchfinder_favorites
- researchfinder_theme

Saved information remains available after refreshing
the browser unless the browser's website data is cleared.

Information is not automatically synchronized
between different devices or browsers.

---

## 13. System Limitations

1. The system does not have student registration or login.
2. The application does not use a shared online database.
3. Research project records are saved locally in each browser.
4. The system does not search external academic websites.
5. The application does not support uploading project documents.
6. The system does not have authenticated administrator access.
7. Sample project records are for demonstration purposes.
8. Changes made on one device do not automatically appear on another.
